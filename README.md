# create-audora-next

Create a new Audora Next.js app with one command.

## Usage

```bash
bunx create-audora-next my-app
cd my-app
bun dev
```

## Requirements

- [Bun](https://bun.sh) runtime

## What's Included

- Next.js with TypeScript
- Tailwind CSS
- ESLint configuration
- Git initialized
